# Student Toolkit

## Background
Shortly after graduating with my bachelor's in computer science, I received an awesome opportunity to teach my own section of a course I had previously TA'd for through a mentor.
The opportunity to teach CS 135 (Computer Science I) at the college level was an amazing experience. My public speaking skills improved dramatically. 
Doing this in the evenings while working a full-time job as a software developer was at times tough though. That's where **Student Toolkit** comes in. 
This project was designed to house all of my course material and information in an easy, modern way that was accessible to both current and past students.
Things like walkthrough recordings, previous programming assignments, and overall student resources are the core of this site. 

## Project Considerations
While working on the design of this project, I placed a few constraints and hard rules on the final product:
- Site had to be easy to maintain. What way to make it easier than by only using HTML/CSS/Vanilla JS? (this also made it easy to host the site on the college's server without any permissions or vulnerability issues that come from a deeper, more advanced tech stack).
- Mobile-first: Every student has a phone. Making the site easy to navigate on mobile was key.
- Clean design: If you click around the site, you'll notice it feels similar to an Apple product. This is intentional, especially given the large market share Apple has on college students. I wanted it to feel familiar and easy to navigate

## Tech Stack
- HTML
- CSS
- JS

The site is kept simple and hosted on the Bellagio server at the College of Southern Nevada.
